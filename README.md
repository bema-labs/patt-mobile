# PATT mobile

The iPhone companion for [PATT](https://github.com/simongtan/patt), a personal
time tracker. It's a Home Screen web app: open the site in Safari, tap
**Share → Add to Home Screen**, then paste your setup code and sign in.

This repository holds only the app's code. It contains no data, keys or
settings - those come from your own setup code and sign-in, and stay on your
phone and in your own Supabase project.
